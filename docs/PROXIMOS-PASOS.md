# Próxima etapa

1. Validar con la Comisión textos, fotografías, zonas pastorales, responsables y datos de contacto.
2. Definir las funciones necesarias: agenda, recursos descargables, inscripción y administración.
3. Conectar el formulario a una API con validación, protección frente a abuso y política de privacidad antes de recoger datos reales.
4. Añadir persistencia para solicitudes y actividades si se aprueba ese alcance.
5. Si se necesita Python, desarrollar una API en `api/` con el entorno Python de Vercel o un servicio independiente, según los requisitos. El frontend puede consumirla desde `public/js/`.
6. Considerar componentes React con herramientas de compilación si aumenta la complejidad; hoy se conserva el motor del prototipo original.
7. Revisar accesibilidad, teclado, dispositivos móviles, permisos de imágenes y dominio definitivo antes de la publicación oficial.

La presentación actual no implementa autenticación, base de datos, envío de correos ni un panel administrativo.
